About

From computer science to data.

I studied Computer Science at the University of the Witwatersrand. Writing software taught me a lot, but the part I enjoyed most was taking a messy problem apart and modelling it. That's what pulled me toward data.

Selected work

Selected work

Things I've built in my own time. Each one links to its repository, with tests and the code behind every number.

01

Credit Risk ECL Engine SAS version in progress

An IFRS 9 expected credit loss engine written in SQL: staging, PD term structure, LGD from resolved workouts, EAD and discounted ECL. I simulated the loan book from a transition matrix I defined, so every estimate can be checked against an exact answer. Per-account ECL matches it to within 1.8e-11, with 161 tests in CI.

SQLDuckDBPythonSASIFRS 9
GitHub ↗
02

Credit Default Scorecard

A probability-of-default scorecard with WOE/IV binning, logistic regression, PDO points scaling and reason codes. Test Gini 0.61 and stable from train to test (PSI 0.03). A gradient-boosted benchmark did no better and overfitted more. I also removed sex from the model and measured the cost: 0.0015 Gini.

PythonCredit riskWOE / IVLogistic regressionValidation
GitHub ↗
03

V8 Quantitative Football Model

A Dixon-Coles match model with Bayesian shrinkage, calibrated probabilities and fractional Kelly staking, tested walk-forward across 13 Premier League seasons. The result: it doesn't beat the bookmakers, and I can show why. On the same matches, the market's probabilities are more accurate than the model's.

PythonDixon-ColesCalibrationBacktestingCLV
GitHub ↗
04

Survey Wave Pipeline

A PySpark pipeline for survey trackers. It maps each wave onto one schema, quarantines bad rows with a reason, and computes weighted NPS and wave-on-wave change with window functions. Re-running a wave never duplicates data, using partition overwrite or Delta Lake MERGE.

PySparkDelta LakeWindow functionsData quality
GitHub ↗
05

compact2binary

A Python tool that turns select-all-that-apply survey answers from compact codes into one 0/1 column per option. A codeframe file describes the survey, and an independent validator re-reads the input to catch unknown codes, miscounts and "None of these" picked alongside real options.

PythonpandasSurveysData transformation
GitHub ↗
06

overlap-qc

Takes compact2binary's output and builds Venn overlap variables, weighted, ready for tabulation. It also flags respondents who tick an implausibly high number of options, using absolute, fractional or outlier rules, and writes everything to a self-contained HTML report.
